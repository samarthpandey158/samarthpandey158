A full-stack grocery delivery application featuring customer shopping, order management, administrator workflows, and delivery partner functionality.

**Key Features**

* 🛍️ Grocery browsing, product selection, and shopping cart.
* 🔐 Authentication with credentials and Google sign-in.
* 📦 Order placement and order status management.
* 🗺️ Location-based functionality and delivery partner tracking.
* ⚡ Real-time communication and location updates with Socket.IO.
* 🤖 AI-powered chat assistant using Google Gemini.
* 📧 Email notifications and OTP functionality.
* 💳 Stripe payment integration.
* ☁️ Cloudinary media management.

**Technology Stack**

`Next.js` `React.js` `TypeScript` `Tailwind CSS` `Node.js` `MongoDB` `Mongoose` `Socket.IO` `Stripe` `Google Gemini`

## 🚀 Featured Project

### 🛒 ShopNest — Grocery Delivery Platform

A grocery delivery web application featuring customer, administrator and delivery partner workflows.

**Key Features**

* 🛍️ Grocery browsing and shopping cart.
* 🔐 User authentication with credentials and Google sign-in.
* 📦 Order placement and status management.
* 🗺️ Map-based location features and delivery tracking.
* ⚡ Real-time communication and location updates using Socket.IO.
* 🤖 AI-powered chat assistant using Google Gemini.
* 📧 Email notifications and OTP functionality.
* 💳 Stripe payment integration.
* ☁️ Cloudinary media integration.

**Built with:** Next.js, React.js, TypeScript, Tailwind CSS, Node.js, MongoDB, Mongoose and Socket.IO.

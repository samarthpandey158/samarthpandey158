### 🛒 ShopNest — Grocery Delivery Platform

A grocery delivery web application with customer, administrator, and delivery partner functionality.

**Features**

* 🛍️ Grocery browsing and shopping cart.
* 🔐 User authentication.
* 📦 Order placement and status tracking.
* 🗺️ Location-based delivery tracking.
* ⚡ Real-time updates using Socket.IO.
* 🤖 AI-powered chat assistant.
* 📧 Email notifications and OTP functionality.
* 💳 Payment integration.

**Built with:** Next.js, React.js, TypeScript, Tailwind CSS, Node.js, MongoDB and Socket.IO.

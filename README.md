## 🚀 Featured Project

### 🛒 ShopNest — Grocery Delivery Platform

A grocery delivery web application designed around customer shopping, order management, and delivery workflows.

**Key Features**

* 🛍️ Browse groceries and manage shopping cart items.
* 🔐 User authentication with credentials and Google sign-in.
* 📦 Place orders and track order status.
* 🗺️ Map-based location features and delivery tracking.
* ⚡ Real-time location updates and communication using Socket.IO.
* 🤖 AI-powered chat assistant using Google Gemini.
* 📧 Email notifications and OTP functionality.
* 💳 Stripe payment integration.
* ☁️ Cloudinary integration for media management.
* 👥 Separate workflows for customers, administrators, and delivery partners.

**Technology Stack**

Next.js · React.js · TypeScript · Tailwind CSS · Node.js · MongoDB · Mongoose · Socket.IO
